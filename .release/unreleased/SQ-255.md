---
ref: SQ-255
title: A dispatch whose WorktreeCreate hook refused before checkout is dispatchable again
bump: patch
plugins:
  - sidequest
---

A dispatch attempt whose WorktreeCreate hook refused before any checkout existed is dispatchable again.

The hook rolled an attempt back only from the catch that runs after `git worktree add` succeeded. Its two
earlier refusals, an incomplete dispatch binding and a lease decision that denies creation, left a
`launched` attempt holding a worktree path that was never created. Rebinding needs that exact path and the
harness names every checkout freshly, so every later spawn was refused `dispatch_binding_unavailable`
permanently, and a replacement token did not help because the new attempt bound against the same absent
path. Both refusals now retire the attempt they can no longer honor and say so, so a plain `dispatch` works
with no recovery flags.

`dispatchNonce` is now the single field both liveness gates read. A launched row whose token was gone was
simultaneously live enough for `dispatch` to refuse it and, by the same refusal's own tail, "not an active
attempt", which left the orchestrator with two refusals and no route.
