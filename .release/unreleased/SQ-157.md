---
ref: SQ-157
title: Full-suite test fixtures leak detached processes that outlive the run
bump: patch
plugins: [sidequest]
---

Dashboard-heal `serve` fixtures and supervisor-exhaustive owned-process trees in the full-suite Node test runner could outlive a passing, failing, timed-out, or cancelled test: `server.test.ts` now spawns those fixtures in their own detached process group and reaps the whole group (SIGTERM then SIGKILL) from a `t.after` hook regardless of outcome, and `test-full-runner.test.ts` tracks each supervisor-exhaustive `onPhaseStarted` owned group the same way.

`scripts/test-full.mjs` adds a `sweepSuiteProcesses` pass that scans for any surviving process whose command line still references the suite's mkdtemp root, SIGKILLs it, removes that temp directory, and then fails naming the leaked pids, so a leak is a loud full-suite failure instead of a silent orphaned process. The match stops at a path boundary, so a sibling suite root sharing the prefix is never touched, and when the functional phase itself failed the leak report is appended to that failure rather than replacing it.
