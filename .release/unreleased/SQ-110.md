title: Describe PR delivery mode on agent-facing surfaces
bump: patch
plugins:
  - sidequest

The `integrate` tool descriptions, CLI help, and the orchestration and publishing references now describe `deliveryChannel` mode `pr`: `integrate` returns `awaiting-merge`, CI on the wave PR is the gate, and a later `integrate` on the same refs reconciles it, with no local full suite, publish lock, or push to `main`. PR-mode `integrate` replies carry a `guidance` field naming the next step, for the `awaiting-merge` state and for the `wave_ci_failed`, `wave_pr_closed_unmerged`, `wave_merge_unreachable`, and `pr_delivery_unavailable` refusals.
