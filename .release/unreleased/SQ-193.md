ref: SQ-193
title: "sidequest: compaction pin now reaches manual-trigger (jev/plugin-fallback) PreCompact events, not just core auto"
bump: patch
plugins: [sidequest]
---

Under fast-jev-compaction, the plugin initiates main-session compaction at 80% of autoCompactWindow and fires classic PreCompact with trigger "manual" (the plugin/`/compact` path hardcodes it), ahead of core auto around 167K. compaction-policy.ts and shared/compaction-policy.ts only emitted the board pin (live claims, dispatches) for trigger "auto", so that jev/plugin-initiated compaction path lost the pin entirely. The pin now emits for trigger "manual" or "auto"; the veto (`decision:block`) still only applies to "auto", so a user-typed `/compact` is never blocked. An unrecognized trigger remains a no-op.
