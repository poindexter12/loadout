ref: SQ-386
title: SessionEnd hands the worktree sweep to a detached worker
bump: patch
plugins:
  - sidequest
---

Exiting a session no longer prints "SessionEnd hook failed: Hook cancelled". The SessionEnd hook ran the worktree sweep inline, which took seconds on a repository with stale agent worktrees, and Claude Code cancels a SessionEnd hook that outlives its shutdown window. Session reconciliation, native-agent cleanup and session unregistration still run before the hook exits; the sweep now runs in the same detached worker SessionStart uses, and its report appears at the next session start. A report the previous worker left unread is kept for that start instead of being overwritten, and SessionEnd does not start a second worker while one for the same checkout is still running.
