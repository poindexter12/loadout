---
ref: SQ-82
title: Stop the worktree sweep traversing node_modules for symlink safety
bump: patch
plugins:
  - sidequest
---

The worktree sweep's symlink guard no longer walks every file in a removal candidate. Recursive removal unlinks nested symlinks instead of following them, so the guard now checks only the hazards that remain: a removal root that is itself a symlink, and quarantine cleanup deleting through a symlinked parent directory. SessionStart sweeps stop paying a full `node_modules` traversal per candidate, and a worktree holding escaping symlinks is removed with the link targets left intact.
