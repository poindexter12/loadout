US-8 wave 0. New `lib/store/question-log` keeps questions and answers out of the board, under `<SIDEQUEST_HOME>/projects/<slug>/questions/`. Each line is one event (`asked`, `sent`, `delivered`, `answered`, `withdrawn`, `carried`) carrying the qid, the ticket ref and a per-ticket seq. Appends hold the log's own `append.lock/` mkdir lock and never the board lock. Readers ignore a torn final line, and the next writer repairs it. `fold.json` lets a reader parse only new bytes, and an inode change, a shrink or a changed head forces a refold. Answers over 2 KiB go to `bodies/<aid>.txt`, which list reads never open. Rotation happens at 1 MiB or at a new UTC month and carries every open or undelivered question forward. Retention is 90 days. The mkdir lock behind the Stop reminder's state file now lives in shared `lib/mkdir-lock`, with the same lock path and the same test gates. Nothing calls the module yet; later US-8 waves wire it to tools.
