---
ref: SQ-308
title: One session can run isolated dispatches on several boards at once
bump: patch
plugins:
  - sidequest
---

The WorktreeCreate hook no longer refuses a spawn with `ambiguous_binding` just because the same session already has live isolated executors on another board. When the session cwd board cannot take the creation, the hook now considers only boards that can actually bind it: one holding an unbound launched dispatch for the session, or one whose dispatch is already bound to the exact checkout this worktree name resolves to there (a re-entered creation). Dispatches already bound to other checkouts belong to earlier spawns and no longer count, so the new checkout lands in the right board's repository while the earlier executors keep running.
