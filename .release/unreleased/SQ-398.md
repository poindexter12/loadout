---
ref: SQ-398
title: Wave PR text strips a local path glued to a preceding character
bump: patch
plugins:
  - sidequest
---

A wave pull request no longer publishes a local absolute path that is glued to the character before it. The sanitizer behind the PR title and body only recognised a path at the start of the text or after whitespace, a quote or a paren, so a ticket title such as `fix: preserve=/Users/alice/private` carried the path straight into the PR on a public repository. Paths after `=`, `:`, `,`, `[`, `<` and `|`, `~/...` home paths, and `C:\...` drive paths are now stripped to `[path]` wherever they appear. URLs, repo-relative and dotted-relative paths, conventional-commit scopes, and fractions or dates such as `1/2` and `2026/11/13` are left alone.
