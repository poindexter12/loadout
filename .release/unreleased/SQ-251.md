---
ref: SQ-251
title: Stop the home-delete guard from blocking ordinary deletes under the home directory
bump: patch
plugins:
  - sidequest
---

The guard now reads each delete's arguments as separate words. A hyphenated path such as `pr-reviews` no longer counts as `-r`, and `~/sub/dir` or `$HOME/sub/dir` no longer counts as the home directory itself. Recursive deletes of `~`, `$HOME`, `${HOME}`, `~/.claude`, the parent of home, `/`, `~/*`, and a bare unknown variable are still blocked.
