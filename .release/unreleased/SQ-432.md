title: "cut.mjs --force-local-tests runs only the suites CI skipped"
bump: patch
plugins: []
---

When the Test run on the pinned commit passed but short-circuited some released plugins' legs, `--force-local-tests` reran every release suite locally, including the ones that run had already executed and passed on that exact commit. On v4.18.0 that meant a 600s+ sidequest suite CI had cleared failed six timing-sensitive tests under ambient load and refused the cut. A normal window now runs only the suites CI skipped, and logs the suites it left out and the run that covered them. A local failure in a skipped suite still refuses. `--force-local-tests` on a pin CI fully covered still runs every suite, a hotfix still runs every suite because it releases cherry-picks rather than the pinned commit, and `--ci-override` and `--skip-tests` are unchanged.
