ref: SQ-356
title: Render a dispatch briefing read-only with `sidequest briefing --dry-run`
bump: minor
plugins:
  - sidequest
---

`sidequest briefing <REF> --dry-run` (alias `--render`) assembles and prints the briefing an
executor would receive, without a dispatch token, a claim, a bound worktree, or any write to the
board. Values a real dispatch mints print as marked `<dry-run: ...>` placeholders, and the full
text always prints inline rather than through the large-briefing file transport.

Until now the assembled briefing was the largest agent-facing surface in Sidequest and the only one
that could not be read without consuming a real dispatch, so any claim about its text, ordering, or
prominence cost an executor to check. The preview renders through the same assembly path and reuses
preparation's own pinned-verifier and evidence-directory resolution, and a test holds it
byte-identical to a real prepared dispatch's briefing so it cannot drift into a separate code path.
