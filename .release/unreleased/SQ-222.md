---
ref: SQ-222
title: Sidequest store and worktrees follow CLAUDE_CONFIG_DIR
bump: patch
plugins:
  - sidequest
---

When `SIDEQUEST_HOME` is unset, Sidequest now keeps its board, dispatch tokens, launcher, and executor worktrees under `$CLAUDE_CONFIG_DIR/sidequest`, and falls back to `~/.claude/sidequest` only when no config dir is set. Previously it always used `~/.claude/sidequest`, so on multi-account machines where `~/.claude` links into one account's tree, sessions from another account wrote their worktrees and board state there. A session using a non-default `CLAUDE_CONFIG_DIR` now starts with its own board under that config dir. Existing state under `~/.claude/sidequest` is not migrated.
