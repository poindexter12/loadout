---
ref: SQ-320
title: Dispatch warnings always reach the compact dispatch result
bump: patch
plugins:
  - sidequest
---

The compact MCP `dispatch` result used to attach `warnings` only when the whole result still fit 1200 bytes, and otherwise dropped them with no marker. A normal dispatch sits near that line, so Dispatch update notices such as a freshly registered Codex pin or a PYTHONIOENCODING write never reached the orchestrator. Warnings now ride the compact result whole, exempt from the spawn budget. If the hard MCP ceiling ever cuts them, the result carries `warningsOmitted` and a `warningsRetrieval` context_page handle that returns the complete list. The CLI `dispatch` now passes the board to the warning check, so board-aware warnings (cross-ticket state changes, sibling scope overlap, verify and worktree checks) appear in its JSON too.
