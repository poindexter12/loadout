---
ref: SQ-335
title: Verify preflight reads quoted node --test flag values as one word
bump: patch
plugins:
  - sidequest
---

The verify-command preflight now reads a `node --test` invocation with shell-word semantics. A quoted flag value such as `--test-skip-pattern="isolated ensure preserves a shim|sibling ensure retires"` is one word, so its spaces and regex `|` alternatives are no longer mistaken for test-file operands and refused with a false "matches no files". An unquoted `|`, `&`, `;`, `<` or `>` still ends the command, and an operand glob that genuinely matches nothing is still refused.
