ref: SQ-178
title: "sidequest: board-owned backup refs under refs/sidequest-backup, surfaced in list/pulse and pruned at done"
bump: minor
plugins: [sidequest]
---

A commit-bearing `checkpoint` now doubles as the board's backup operation: it pins the commit at `refs/sidequest-backup/<REF>/<UTC stamp>` (never overwriting an existing backup) with a reflog, and returns it as `checkpoint.backupRef` (or `checkpoint.backupError` when the commit is not in the repository). `pulse` and `list ref:` return the ticket's `backupRefs` plus any `unrecognizedRefs`, meaning refs under `refs/sidequest/` the board did not write, such as a hand-made `refs/sidequest/SQ-106-preserve`. Board `list` returns per-ticket backup counts and unrecognized refs board-wide. MCP `done`, `groomClose`, and `integrate` delivery prune every backup whose ticket is done, and `done`/`groomClose` report them as `backupRefsPruned`. Board ref writes (submission pins, rejection quarantine refs, worktree salvage refs) now pass `--create-reflog`, so their moves are auditable. The publishing reference documents the namespace and replaces improvised backup refs.
