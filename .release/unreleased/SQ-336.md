---
ref: SQ-336
title: The drain-fallback restart test no longer fails under host load (test-only change)
bump: patch
plugins: [model-gateway]
---

The test `confirmed legacy worker supports restart through the drain fallback` failed whenever the host was busy. Before restarting, the controller checks which process owns the gateway port, using real `netstat`, `lsof`, and `ps` calls. Under load each call took 9 to 16 seconds, so the default 2 second limit ran out and the controller refused before it reached the drain. The test now gives those calls 60 seconds and the drain 30 seconds. The owner check is still real. Shipped plugin behavior is unchanged.
