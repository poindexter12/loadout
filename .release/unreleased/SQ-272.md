---
ref: SQ-272
title: "sidequest: guide recovery of dead claimed runtimes"
bump: patch
plugins: [sidequest]
---

When recovery evidence identifies a failed host task for a dispatch that was already claimed, Sidequest no longer tells the orchestrator to wait for a terminal record. That record cannot arrive for an executor that died at the model API, so the refusal now gives the existing forced-claim-release guidance instead.
