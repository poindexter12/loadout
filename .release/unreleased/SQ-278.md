title: Release fragments are opt-in per repository
bump: patch
plugins:
  - sidequest
---

Submit and delivery close no longer demand a `.release/unreleased/<ref>.md` fragment from a repository that has no `.release/` directory, such as one releasing through Release Please. Repositories that keep `.release/` still require a fragment for every shipped plugin change, and the refusal now says why.
