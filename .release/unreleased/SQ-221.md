---
ref: SQ-221
title: Executor briefings no longer flag their own worktree as a leftover board server cwd
bump: patch
plugins:
  - sidequest
---

Isolated-worktree executor briefings no longer warn that the board server cwd is a leftover linked worktree and tell you to restart the session. The check read the working directory of the process rendering the briefing, which is the executor sitting in the worktree its own dispatch created. It now ignores the dispatch's bound worktree and still warns for any other linked worktree.
