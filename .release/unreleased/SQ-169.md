---
ref: SQ-169
title: Verify capture sizes its time budget to the command and the machine's load, with a hard maximum
bump: patch
plugins:
  - sidequest
---

Captured verify runs no longer die at a fixed 600000ms unless the command is `npm run test:full`. Any test-suite command now gets the same budget the full suite gets: any `node --test` run, `npm test`, `npm t`, or `npm run test[:name]`. That budget is the setup allowance plus extra time that grows with how loaded the machine is. Other commands keep the 600000ms allowance. `SIDEQUEST_FULL_SUITE_PHASE_BUDGET_MS` still only ever adds time, and it now applies to every capture. Every capture stops at a two-hour hard maximum, so a hung run cannot hold the per-host capture slot forever. A run that runs out of time reports `capture_budget_exceeded` along with how long it ran, the budget and how it was derived, the load at the start and at the deadline, and how to raise the budget. The wrapper announces the budget before the run and prints a `capture-budget` line after it.
