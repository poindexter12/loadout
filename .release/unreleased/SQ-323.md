---
ref: SQ-323
title: Negative-control gate no longer reads fixture data as test names
bump: patch
plugins:
  - sidequest
---

The negative-control gate now recognizes test definitions only in languages whose syntax it knows (JS/TS/Dart `test`/`it`/`specify` calls and Python `def test_`). A jq `test("<regex>")` filter or a quoted fixture name in a shell suite is no longer demanded as a test, and neither is a regex literal `.test('x')` call. The refusal quotes each required test name so a name containing a comma or pipe reads as one name, and an `unaffected <name> because <reason>` marker for it clears the gate.
