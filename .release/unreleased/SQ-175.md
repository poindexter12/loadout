Each Claude config dir now gets its own shim/proxy port pair: the default tree (physical ~/.claude) keeps 18764/18765, and every other tree derives a stable pair in 20000-27999 from its path. ensure rewires an old 127.0.0.1:18764 ANTHROPIC_BASE_URL in a non-default account to its own port; restart Claude Code sessions there afterward. When the port is held by another install root, Codex readiness now names that PID and install root and gives the real remedy instead of prescribing ensure. CODEX_GATEWAY_PORT / CODEX_GATEWAY_PROXY_PORT still override.
