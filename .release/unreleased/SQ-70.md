---
ref: SQ-70
title: Resolve the verification capture board from the dispatched ticket, not the inherited worktree
bump: patch
plugins: [sidequest]
---

Verification capture resolved its board from the `--project` path it was handed,
so a re-dispatched executor standing in a retired agent's worktree recorded
nothing and got a bare `project_not_found` pointing at project registration
rather than at worktree reuse. An unregistered `--project` now folds to the
repository root that owns it, which maps a linked worktree back onto the board
that dispatched the ticket, and the full-suite capture slot is keyed on the
registered project path so a stale spelling can no longer strand captures in a
private slot namespace. When resolution still fails the message names the paths
tried and the `--project` source, and a checkout with no resolvable HEAD is
reported as the dead worktree it is. The deferred SessionStart sweep notice now
states that its counts are a snapshot at the budget rather than a final result.
