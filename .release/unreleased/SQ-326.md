title: "sidequest: name groomClose recovery for landed work in closeout refusals"
bump: patch
plugins: [sidequest]
---

The `claim_released` and `submission_required` closeout refusals now distinguish unlanded executor work from verified work that has already landed. Both retain the executor redispatch and submit route where it applies, and now name `sidequest groomClose <ref> --by <integrator> --deliveryCommit <sha>` for the sanctioned control-plane delivery record after a terminal dispatch.
