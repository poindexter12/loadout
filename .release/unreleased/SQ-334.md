ref: SQ-334
title: verify-capture serializes the direct full-suite entry point and names its slot per-project
bump: patch
plugins:
  - sidequest
---

A ticket-bound capture of `node scripts/test-full.mjs` (bare, path-qualified, quoted, or with flags before the script) is now classified as the full suite, so it takes the project's capture slot and the full-suite budget like `npm run test:full`. Before, only the npm spelling matched, so two direct runs in one project ran side by side. The slot-wait refusal, the slot-failure reason, the queue notice and the `full-suite` budget description no longer call the slot "per-host": they say it is per project and that captures in other projects on the same host are not serialized against it, so keeping cross-project suites apart stays the operator's job. The slot keying is unchanged.
