---
ref: SQ-31
title: model-gateway caps its own logs at 10MB and stops creating the log directory on every request
bump: patch
plugins: [model-gateway]
---
`proxy.log`, `guardian.log`, and `request-routes.jsonl` grew without any bound; one install reached 19MB of `proxy.log` alone. Every `ensure` now rotates any of the three that passes 10MB, keeping a single `.1` predecessor and truncating the live file in place so a running proxy or supervisor keeps writing to it. The request route log also no longer re-creates its directory on every request.
