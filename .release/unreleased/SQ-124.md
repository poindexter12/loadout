---
ref: SQ-124
title: Verification timeout kills the whole verify process tree
bump: patch
plugins:
  - sidequest
---

When a verify command times out, whether in executor verify capture or merged-tree integration verification, Sidequest now kills the command's whole process group. It sends SIGTERM, then SIGKILL after a 5-second grace period. Before this, it signalled only the shell, so child test runners such as per-file `node --test` processes kept running and slowed the next verification. The verification log and timeout evidence now record that the process tree was killed.
