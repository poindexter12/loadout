ref: SQ-65
title: Scale dashboard start and test spawn waits with machine load
bump: patch
plugins:
  - sidequest
---

The dashboard start wait now honors `SIDEQUEST_DASHBOARD_START_DEADLINE_MS`, keeping its 9-second default otherwise. The test suite sets it, and its remaining fixed spawn waits, from the shared per-worker capacity deadline, so a busy machine no longer fails them at random.
