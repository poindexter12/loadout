---
ref: SQ-389
title: The test sandbox no longer inherits SIDEQUEST_* tuning overrides
bump: patch
plugins:
  - sidequest
---

Widening the full-suite phase budget is the documented way to get a release cut through a loaded machine, but `SIDEQUEST_FULL_SUITE_PHASE_BUDGET_MS=5400000` was inherited by every child the suite spawned, so the SQ-225 detached-capture test read back a 6000000ms budget where it asserts 600000ms and the v4.15.0 cut went red on it. The test-home preload now scrubs every inherited `SIDEQUEST_*` variable the sandbox does not own before it pins anything, a prefix sweep against an allowlist rather than a list of known-bad names, so the next tuning knob cannot leak the same way. The outer runner still samples its own budget before spawning the phase, and a test that exercises an override sets it on the environment it hands its child. `scripts/test-full.mjs` exports its phase-environment builder so the suite asserts every `SIDEQUEST_*` name it pins is on that allowlist, which is what keeps a future pin from being scrubbed out from under the phase.
