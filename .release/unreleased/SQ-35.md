ref: SQ-35
title: model-gateway keeps one copy of the shim request-path, readiness and state-path code
bump: patch
plugins: [model-gateway]
---

`lib/commands.js` no longer carries about 550 lines of private copies of code that runs in `lib/request-worker.js`. The dead copies are gone: the compaction and SSE helpers, a stale two-argument `upstreamErrorMessage`, the route telemetry block, and an unused `DispatchSessionRouteCache`. `lib/request-worker.js` likewise drops its never-called copy of the catalog write/read commands, which only the CLI runs. The upstream-block and readiness helpers, the shim health probe and dispatch-route parsing are now imported from `request-worker.js`, and `STATE`, the route-log path and the other state constants come from `runtime.js` alone. Nothing changes at runtime. The exported API is the same, and tests that used the old copies now exercise the code that actually serves requests. A new `test/single-source.test.js` fails if a copy comes back.
