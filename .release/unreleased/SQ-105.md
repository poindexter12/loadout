---
ref: SQ-105
title: Integrate opens one pull request per wave with auto-merge when the board uses PR delivery
bump: patch
plugins:
  - sidequest
---

With the board delivery channel set to `pr`, `integrate` no longer moves main. It builds the wave from the remote target, pushes `sidequest/wave/<wave>`, opens one pull request with auto-merge enabled, and reports the wave as awaiting merge while its tickets stay in progress. Integrating the same wave again returns the open pull request. When the GitHub CLI or the remote is unavailable, integrate refuses with the cause and leaves nothing behind. Local delivery is unchanged.
