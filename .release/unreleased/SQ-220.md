---
ref: SQ-220
title: Keep live executor launches alive across compaction and subagent session starts
bump: patch
plugins: [sidequest]
---

Session-start maintenance now fails a launched-but-unclaimed dispatch only when the main session actually restarts (startup or resume). Compaction, /clear, and a subagent's own session start no longer mark a live executor's dispatch as process_death before it can claim.
