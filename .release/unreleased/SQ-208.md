ref: SQ-208
title: Full suite starts its longest test files first
bump: patch
plugins:
  - sidequest
---

`npm run test:full` now starts the six longest serial test files first (hooks, mcp, dispatch-lifecycle, integration-advance, submission, worktree-isolation) instead of in alphabetical order. It does this through an order-preserving phase root. Before, those files started up to eight minutes into the phase and ran past the budget on an idle machine while most workers sat empty. The checkpoint test fixture also pins its repository's default branch to `main`, so it no longer fails on hosts whose git defaults to a different branch name.
