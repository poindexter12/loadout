ref: SQ-137
title: Heaviest sidequest test files split into topic shards
bump: patch
plugins:
  - sidequest
---

The four slowest sidequest test files (hooks, mcp, submission, integration-advance) are split into topic shards that share one fixture module each, so the test runner can spread them across workers instead of running each as a single serial chain. Test count and assertions are unchanged.
