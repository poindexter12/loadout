---
ref: SQ-383
title: "Groom-close can record forge-merged work as delivered: squash merges, deleted PR branches, and checkouts on another branch"
bump: patch
plugins: [sidequest]
---
A frozen dispatch target whose PR branch the forge deleted now falls back to the board target (and abandonment no longer needs any target). Remote-mode deliveries are judged on the remote even when the checkout sits on another branch, and a squash that cleanly merged the candidate with a concurrent edit to a shared file is accepted as a `forge-squash` delivery, with the merged paths recorded.
